# Encargos pendientes del Aguijón

Seis encargos cortos para terminar el Aguijón. Hazlos **uno a uno y en este orden**:

| # | Archivo | Qué añade |
|---|---------|-----------|
| 1 | `01_Hormiga.md` | Forma `Ant`: Aguijón + Patas articuladas (insecto + artrópodo) |
| 2 | `02_Ninfa.md` | Forma `DragonflyNymph`: Aguijón + Aletas (insecto + marino) |
| 3 | `03_Zapatero.md` | Forma `WaterStrider`: Aguijón + Vejiga de tinta (insecto + cefalópodo) |
| 4 | `04_Escarabajo.md` | Forma `Beetle`: Aguijón + Caparazón (insecto + tortuga) |
| 5 | `05_Oruga.md` | Forma `StingingCaterpillar`: Aguijón + Piel urticante (insecto + erizo) |
| 6 | `06_Esquiva_Aguijon.md` | Esquiva del rasgo del Aguijón (el abdomen enroscado al rodar) |

Para cada encargo:
1. Abre una **conversación nueva** con Claude.
2. Adjunta **solo** `generar_cuerpo_evolutivo.py`, la versión más reciente de esta carpeta. Después de cada encargo, Claude Code le añade lo nuevo, así que el siguiente parte de lo anterior.
3. Pega el texto del archivo, desde la línea `---` hacia abajo.
4. Comparte la respuesta con Claude Code. Él la pega en el script, lo ejecuta, te enseña la vista previa y lo importa en Unity.
5. Cuando des el visto bueno, pasa al siguiente.

Si una forma no te convence, no la vuelvas a encargar entera: dile a Claude Code qué cambiar y él lo retoca en el script.
