# Iconos de las especiales del ámbar (piso 3)

Aprobados el 2026-11-23 (Opus). Sustituyen a `floor3-mutations/Icons/Icon_{Cerci,AmberCapsule,AmberDrop}_{32,16}`
(mismos nombres): al importar, copiar estos encima o apuntar el menú `Primordia > Floor 3 > Crear mutaciones especiales
del ámbar` a esta carpeta.

| Hoja | Celda | Qué es |
|---|---|---|
| Icon_Cerci_32 / _16 | 32×32 / 16×16 | Dos cercos segmentados en V con las puntas de ámbar |
| Icon_AmberCapsule_32 / _16 | 32×32 / 16×16 | Cápsula en forma D (borde rojizo, reflejo, veta) con un corazón cálido dentro |
| Icon_AmberDrop_32 / _16 | 32×32 / 16×16 | Cristales de ámbar del lomo con una gota que cae al lado |

Marca común de las especiales: **contorno dorado `#f2c24e`** (no el morado OUTL) y **destello en estrella** arriba a la
derecha, quieto. Un cuadro, sin animación.

Regenerar: `python generar_iconos_ambar.py` (vistas previas: `vista_previa_iconos_antes_despues.png`,
`vista_previa_iconos_juntos.png`).
